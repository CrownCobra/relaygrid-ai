# Start here

This project is being deployed on Netlify. The no-key lead workflow is a demonstrable rules-based workflow, not a live AI agent.

## Fastest route

1. Open the existing Netlify site connected to this GitHub repository.
2. Keep the build command empty and publish directory set to `public`; `netlify.toml` already defines the deploy settings.
3. Enable Netlify Forms form detection and deploy the current GitHub branch.
4. Submit a made-up test enquiry. Confirm the website shows the issue category and a response draft.
5. Open the site's Forms tab and confirm the test submission is recorded. Review new enquiries there manually.

No API key is needed or to be added. Do not add billing details or upgrade a plan. The workflow uses rules to classify and draft; no message is sent automatically. The chat and Agent Workspace remain demos.

If anything in the Netlify dashboard differs from these steps, stop at that screen and share a screenshot so the next click can be identified.
