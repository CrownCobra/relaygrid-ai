Core workflows

Four fixes. One clear pipeline.

Every project starts with a short audit and uses your current tools where practical. The exact integrations depend on the systems you already have.

MODULE / 01＋

Enquiry capture

Consolidate web form and referral enquiries into one tracker with source, contact details, project location, owner and status.

MODULE / 02⌂

Qualification & site visits

Give staff a repeatable way to record capacity interest, property type, timeline, utility details and next action. Sensitive or technical decisions stay with the team.

MODULE / 03▤

Quote follow-up

Create due dates and approved message drafts for unanswered proposals. Staff review before sending; no unsolicited mass-message sequences.

MODULE / 04◷

Daily / weekly digest

Surface new, overdue and stalled leads so the owner can act without manually rebuilding a report.

MODULE / 05◎

Knowledge-based FAQ helper

Optionally draft answers from the installer's approved service information, FAQs and service areas, with handoff when confidence is low.

MODULE / 06✓

Outcome tracking

Track response time, site visits booked, proposals followed up and won/lost reasons. Baseline first; claims only after evidence.

How we build

Automate the repeatable. Keep people in charge.

For the first pilot, we usually avoid buying a full CRM or paying for a WhatsApp API before a workflow has proven useful.

  • Google Sheets / Forms / Gmail or tools already owned by the client
  • Lightweight scripts and open-source automation when suitable
  • Approved templates, opt-outs and a human review step
  • Client-owned accounts, documented access, and a handover guide
  • Clear boundaries around data, AI output and support
Important: automated WhatsApp messaging, telephony, SMS, LLM usage and third-party connectors may have fees, eligibility rules or platform policies. These are not included unless explicitly scoped.
