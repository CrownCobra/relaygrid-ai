# RelayGrid AI

A Netlify-first starter for demonstrating one workflow for rooftop-solar businesses: capture an enquiry, classify the issue, draft a reply, and record it for human follow-up.

## What works in the no-key setup

- The static website is in `public/`.
- A Netlify Function validates the enquiry, classifies it with simple rules, and prepares a response draft.
- Netlify Forms is the intended inbox; storage remains unverified until a matching synthetic submission is visible. Detection was disabled at the setup check.
- The draft is displayed for human review. The site does not send email, WhatsApp messages, or other outreach.
- The chat widget uses local canned FAQ replies without sending chat text. The animated Agent Workspace is a browser-only simulation.

No AI API key or paid AI service is needed for this demo workflow. The workflow contains no model-provider or Cloudflare calls; no environment variables are needed. The draft is rule-based, not generated by a live AI model.

## Deploy on Netlify

Use the existing Netlify site connected to this GitHub repository. The included `netlify.toml` sets the publish folder to `public`, deploys functions from `netlify/functions`, and routes `/api/lead-workflow` to the lead workflow function.

1. In the existing Netlify site, confirm it is connected to this repository and the intended branch.
2. Keep the build command empty and the publish directory set to `public`. The repository config already supplies these settings.
3. Enable Netlify Forms form detection, then deploy the site.
4. Submit a synthetic enquiry. Confirm the page shows a category and draft, then verify the submission appears in the site's Forms tab.
5. Review every new submission manually in Netlify. Configure a monitored notification address in Netlify only if you want email alerts; the website does not send replies.

Do not enter billing details or upgrade a plan for this demo. Do not add API keys or secrets to the repository. Do not configure an AI provider. The no-key workflow is the intended setup.

## What this does not do

- It does not use a live AI model to create the draft.
- It does not automatically email or message the enquirer.
- It does not create CRM tasks or schedule follow-up reminders.
- The chat and Agent Workspace are demos, not live agents.
- It cannot guarantee revenue or customer results.

The `functions/` directory contains a separate backend from an earlier version; Netlify deploys the function in `netlify/functions/`.

## Local checks

Run `python scripts/check_site.py` to check local pages and assets. JavaScript syntax can be checked with `node --check public/assets/js/main.js`, `node --check public/assets/js/config.js`, and `node --check netlify/functions/lead-workflow.mjs`.

Before collecting real enquiries, replace the operator and privacy placeholders in `public/privacy.html`, decide how long to retain submissions, and confirm who checks the Netlify Forms inbox.

Run `node --test tests/*.test.mjs` for workflow validation and client failure-path tests. See `docs/DEPLOYMENT.md` for the exact remaining Netlify setup and verification steps. No push or deploy was performed during this local update.
